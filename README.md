# مِداد — محرر فيديو عربي محلي

مِداد محرر محلي لتحويل الفيديوهات إلى مقاطع قصيرة: اقتراحات نشاط صوتي، تحليل دلالي محلي اختياري بـOllama، قص يدوي، مسارات متعددة، ترجمة كلمة بكلمة، مؤثرات، وحفظ مشاريع وتصدير MP4 عبر Remotion.

## التشغيل

1. Node.js 20+ وPython 3.10+.
2. `npm install`
3. `python -m pip install -r analyzer/requirements.txt`
4. لتفريغ الكلام، اترك `WHISPER_MODEL=base` (الافتراضي) ثم شغّل `npm run dev` وافتح `http://localhost:5173`.

يعمل faster-whisper محليًا ويحمّل أوزان النموذج أول مرة. `base` أقل استهلاكًا للذاكرة، ويمكن اختيار `small` أو `medium` مع توافر ذاكرة إضافية. يعطي Whisper كلمات وجملًا بطوابع زمنية، ويكتشف اللغة تلقائيًا. يمكن تصحيح كل كلمة بالنقر المزدوج عليها مع الاحتفاظ بتوقيتها. جودة النص تعتمد على وضوح الصوت والنموذج.

## تحليل محلي للمشاهد والمقاطع

يكتشف PySceneDetect تغيّر المشاهد، ويستخدم OpenCV لعينات الحركة والحدة والسطوع والوجوه وصور المعاينة. تحليل المقاطع الدلالي يرسل نص Whisper وجمله الموقّتة إلى Ollama، ثم يحدّ حدود المقاطع إلى كلمات وجمل كاملة، ويتحقق من بقائها داخل مدة الملف. تظل مؤشرات الطاقة الصوتية اقتراحات استدلالية ولا تُسمّى فهمًا دلاليًا.

ثبّت Ollama وشغّله محليًا، ثم نزّل النموذج:

```powershell
ollama pull qwen3:8b
ollama serve
```

الإعداد الافتراضي `OLLAMA_MODEL=qwen3:8b`. حجم نسخة Q4 المنشورة نحو 5.2GB، إضافة إلى ذاكرة التشغيل. على الأجهزة محدودة الذاكرة يمكن اختيار نموذج أصغر موجود في Ollama، مثل `qwen3:1.7b` أو `qwen3:4b`، بواسطة `OLLAMA_MODEL`. لا تُرسل ملفات الفيديو إلى Ollama؛ لا ترسل إليه إلا النص وإطارات مصغرة عند ضبط نموذج رؤية اختياري.

اختُبر استدلال المقاطع فعليًا محليًا على عينة عربية باستخدام `qwen3:1.7b`. النموذج الافتراضي `qwen3:8b` مثبّت، لكن لم يُعتمد نجاح استدلاله على هذا الجهاز: لديه 8GB RAM وRTX 2050 بذاكرة 4GB، وظهرت محدودية الموارد أثناء التجربة. لذلك لا تعتبر وجود النموذج في قائمة Ollama دليلًا على نجاح الاستدلال؛ حالة النظام تعرض الاتصال ووجود النموذج، وتظهر أخطاء التشغيل بدل إنشاء اقتراحات وهمية.

اختياريًا، اضبط `OLLAMA_VISION_MODEL` على اسم نموذج رؤية يدعم الصور. تُحلل حتى أربعة إطارات مشهد. عند غياب النموذج تستمر الميزة باستخدام النص وقياسات OpenCV المحلية.

## أدوات التحرير

- قص يدوي، مشغّل، موجة صوت، ومؤشرات بداية/نهاية، مع Timeline متعدد المسارات.
- اقتراحات المقاطع تعرض التوقيت والسبب والدرجة والمعاينة إن توفرت. يمكن تحديد المقطع وقصه يدويًا، اعتماده أو رفضه، وإعادة ترتيبه. الاقتراحات لا تستبدل تعديلاتك اليدوية.
- اقتراحات تحرير من قائمة آمنة؛ لا تُطبق إلا عند قبولها. تشمل إبراز عبارة، تقريبًا خفيفًا، اقتصاصًا رأسيًا ذكيًا عند توفر رصد وجه، وتلاشي دخول/خروج باستخدام EffectEngine.
- قوالب ترجمة للكلمات النشطة، التفاف تلقائي للأسطر واتجاه تلقائي للنص المختلط، تصحيح كلمة مع الإبقاء على توقيتها، ومسار نص يدوي.
- تُستخدم أسماء الخطوط `Thmanyah Sans` و`Thmanyah` أولًا، ثم خطوط النظام البديلة. ملفات خط ثمانية ليست مضمنة في المستودع؛ الخط الرسمي متاح من [موقع ثمانية](https://font.thmanyah.com/) ويجب استخدامه وفق شروط المصدر.
- مؤثرات تشمل التعريض والتباين والتشبع والحرارة والتمويه والتظليل والحبيبات والتقريب والاهتزاز والتلاشي. نفس محرك المؤثرات يستخدم في المعاينة والتصدير.
- لوحة حالة محلية تعرض Ollama وWhisper وGPU والذاكرة والمهام الحالية.
- حفظ المشاريع محليًا واستعادتها. إخراج H.264/AAC عمودي 1080×1920 أو أفقي.

## الإعدادات والاختبارات

`PORT`, `MEDAD_DATA_DIR`, `PYTHON_BIN`, `WHISPER_MODEL`, `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_VISION_MODEL`, `OLLAMA_TIMEOUT_MS`, `OLLAMA_NUM_CTX`, `REDIS_URL`, `WORKER_CONCURRENCY`.

- `npm run build`: بناء الواجهة.
- `npm test`: اختبارات المؤثرات والمسارات ومحاذاة حدود الجمل واختبار تكامل كامل مع FFprobe واستخراج الإطارات واستعادة المشروع.
- بيانات التكامل تكتب في مجلد مؤقت معزول، ولا تستخدم مكتبة مشاريع المستخدم.

`npm start` يشغّل API محليًا وطابور المهام داخل العملية؛ Redis اختياري عبر Docker Compose. استيراد YouTube غير مدعوم؛ يمكن استيراد رابط مباشر عام لملف فيديو. قبل تعريض الخدمة على الإنترنت، أضف المصادقة وعزل المستخدمين والتخزين والحصص.
